# QWIKSELLER Scan

Scanner d'articles pour iPhone : caméra en direct, zoom, articles séparés, suppression rapide, envoi AirDrop vers le Mac. Les photos ne vont pas dans la galerie.

En ligne : https://yanis0u-10jr.github.io/QWIK-SCAN/

Sur iPhone : ouvrir le lien dans Safari → Partager → « Sur l'écran d'accueil ».
